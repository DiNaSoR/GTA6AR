# دليل تثبيت الترقيع، خطة اختبار الجودة، وقائمة التحقق للإصدار 1.0 — User Install Guide, QA Plan & v1.0 Release Checklist

تجمع هذه الوثيقة متطلبات المعلم السابع والأخير (Milestone 7): **خطة اختبار التعريب على نسخة اللاعب الأصلية (`#22`)**، و**قائمة التحقق قبل الإصدار 1.0 (`#23`)**، و**دليل تثبيت الترقيع للمستخدم النهائي (`#24`)**.

> **تنويه قانوني مهم:** مشروع **GTA6AR** لا يوزّع ولا يستضيف أي ملفات من اللعبة الأصلية. لتثبيت الترقيع أو المشاركة في اختبارات الجودة، **يلزمك امتلاك نسخة أصلية قانونية من لعبة Grand Theft Auto VI**.

## القسم الأول: دليل تثبيت الترقيع للمستخدم (User Install Guide — Issue #24)

### 1. المتطلبات الأساسية
1. **نسخة أصلية قانونية ومحدّثة** من لعبة **Grand Theft Auto VI**.
2. مساحة خالية إضافية على القرص الصلب لا تقل عن `5 GB` لملفات الترقيع الصوتي والرسومي والنسخة الاحتياطية المحلية.
3. حزمة أدوات وترقيع **GTA6AR** الرسمي المحمّل من صفحة الإصدارات ([Releases](https://github.com/DiNaSoR/GTA6AR/releases)).
4. بيئة **Python 3.10+** (أو أداة التثبيت التنفيذية المرفقة في الإصدارات المستقرة).

### 2. خطوات التثبيت بالترتيب
1. **إنشاء نسخة احتياطية محلية:**
   قبل تطبيق أي تعديل، احتفظ بنسخة احتياطية من ملفات اللغة/الواجهة في مجلد التثبيت المحلي للعبتك حتى تتمكن من استعادة الحالة الأصلية في أي وقت.
2. **التحقق من سلامة حزمة الترقيع:**
   تأكد من تحميل أحدث إصدار من مستودع `DiNaSoR/GTA6AR`، وشغّل فحص السلامة:
   ```bash
   python tools/verify_repo_cleanliness.py
   ```
3. **معاينة الترقيع النصي والخطوط (اختياري):**
   يمكنك معاينة الحزم النصية واتجاه RTL قبل الحقن عبر:
   ```bash
   python tools/text_tool.py preview --patch text/patches/ui/ui-main-001.patch.json --output preview.html
   ```
4. **تطبيق الترقيع على نسختك المحلية:**
   وجّه أداة الحقن إلى المسار المحلي لجدول النصوص على جهازك مع تمرير ملف الترقيع العربي:
   ```bash
   python tools/text_tool.py inject \
     --source "/path/to/local/game/strings_table.json" \
     --patch "text/patches/ui/ui-main-001.patch.json" \
     --output "/path/to/local/game/strings_table.patched.json" \
     --bidi-isolate
   ```
5. **تشغيل اللعبة وتفعيل الترجمة:**
   شغّل اللعبة، وانتقل إلى **الإعدادات (Settings) → الصوت (Audio) → الترجمة النصية (Subtitles)** وتأكد من تفعيلها.

### 3. حل المشاكل والأخطاء الشائعة (Troubleshooting — بدون رفع ملفات اللعبة)
- **المشكلة 1: ظهور رسالة `Source hash mismatch` أثناء الحقن:**
  - **السبب:** تحديث جديد للعبة غيّر السلسلة النصية الأصلية عن النسخة التي بُني عليها الترقيع.
  - **الحل:** تأكد من تطابق رقم إصدار الترقيع مع تحديث اللعبة، أو أبلغ عن المعرّف (`id`) فقط في قسم [القضايا (Issues)](https://github.com/DiNaSoR/GTA6AR/issues) **دون إرفاق أي ملف من اللعبة**.
- **المشكلة 2: انعكاس مكان علامات الترقيم أو رموز الأزرار (`~INPUT_...~`):**
  - **الحل:** أعد تشغيل أمر الحقن مع تفعيل خيار `--bidi-isolate` (وأضف `--shape` إذا كانت الواجهة لا تدعم ربط الحروف تلقائيًا).
- **المشكلة 3: الرغبة في إزالة التعريب والعودة للغة الأصلية:**
  - **الحل:** استبدل الملفات المعدّلة بالنسخة الاحتياطية المحلية التي أنشأتها في الخطوة (1)، أو استخدم خيار «التحقق من سلامة ملفات اللعبة (Verify Game Files)» في مشغّل اللعبة الرسمي.

## القسم الثاني: خطة اختبار التعريب على نسخة اللاعب الأصلية (QA Plan — Issue #22)

يُجري المختبرون الفحص محليًا على نسختهم الأصلية القانونية، ويرفعون تقاريرهم عبر [قالب بلاغ الخلل](https://github.com/DiNaSoR/GTA6AR/issues/new?template=bug.yml) بالاكتفاء بذكر **معرّف السلسلة (`String ID`) أو اسم الدفعة (`Batch ID`)** دون رفع لقطات تحتوي على أصول خام أو ملفات مستخرجة.

### سيناريوهات الاختبار الأربعة:
| المسار | عناصر الفحص الأساسية | معيار القبول (Pass Criteria) |
|---|---|---|
| **1. الواجهة والقوائم (UI & Menus)** | القائمة الرئيسة، الإعدادات، الخريطة، إشعارات الشاشة (HUD)، والهاتف. | عدم تجاوز النص حدود الأزرار، سلامة اتجاه RTL، وظهور رموز الأزرار (`~INPUT_...~`) في مواضعها الصحيحة. |
| **2. الترجمات الفرعية والحوار (Subtitles)** | المشاهد السينمائية، حوارات القيادة، والمكالمات. | حد أقصى سطران لكل جملة، توافق ظهور واختفاء السطر مع كلام الشخصية، وسلامة الفصحى. |
| **3. الدبلجة الصوتية (AI Voice Dubbing)** | نبرة الشخصيات الرئيسة، مخارج الحروف، ومواءمة التوقيت (`timing_ms`). | نطق فصيح سليم خالٍ من التقطيع، وتطابق مدة المقطع الصوتي مع نافذة المشهد بفارق لا يتجاوز `±8%`. |
| **4. الصور واللافتات (AI Images & Signs)** | لافتات الطرق، واجهات المتاجر، والخرائط الإرشادية. | حروف عربية متصلة وصحيحة الاتجاه، تباين واضح (`>= 4.5:1`)، واستخدام الخطوط المرخّصة المعتمدة. |

### نموذج تقرير الفحص المحلي (QA Report Template — خالٍ من أصول اللعبة):
```markdown
- **رقم دفعة الترقيع / Batch ID:** `ui-settings-001`
- **معرّف السلسلة أو العنصر / Entry ID:** `UI_GFX_VSYNC`
- **المسار / Area:** الواجهة / UI
- **وصف الملاحظة (بدون لصق نصوص أو ملفات اللعبة الأصلية):** النص العربي يتجاوز عرض الزر في دقة 1080p بـ 4 أحرف تقريبًا.
- **الاقتراح الفصيح البديل:** استبدال «المزامنة الرأسية للشاشة» بـ «المزامنة الرأسية».
```

## القسم الثالث: قائمة التحقق قبل الإصدار 1.0 (v1.0 Release Checklist — Issue #23)

لا يُعلن عن **الإصدار 1.0** إلا بعد استيفاء البنود التالية بالكامل واجتياز فحص `python tools/verify_repo_cleanliness.py`:

- [ ] **1. اكتمال التغطية في المسارات المستهدفة:**
  - [ ] اكتمال ترقيعات واجهة المستخدم والقوائم (`text/patches/ui/`).
  - [ ] اكتمال ترقيعات الترجمات الفرعية للمشاهد والمهمات الرئيسة (`text/patches/subtitles/` و `text/patches/missions/`).
  - [ ] اكتمال حزم الدبلجة الصوتية المعتمدة (`audio/manifests/`) وحزم الصور الأساسية (`images/manifests/`).
- [ ] **2. الالتزام الصارم بالنماذج المعتمدة وتوثيق الإصدار:**
  - [ ] جميع ملفات النصوص منتجة بـ **Gemini 3.8 Flash أو أقوى** وموثّقة في حقل `generator`.
  - [ ] جميع ملفات الدبلجة منتجة بـ **ElevenLabs v4 أو أقوى** وموثّقة في حقل `generator`.
  - [ ] جميع ملفات الصور منتجة بـ **OpenAI Sunburn أو أفضل** وموثّقة في حقل `generator`.
- [ ] **3. اجتياز الفحوصات الآلية واللغوية:**
  - [ ] نجاح `python tools/check_glossary.py` بصفر مخالفات للمسرد والـ Placeholders وحدود الطول.
  - [ ] نجاح جميع اختبارات الوحدة (`python -m unittest discover -s tools/tests -v`).
- [ ] **4. النظافة القانونية والأمنية للمستودع:**
  - [ ] نجاح `python tools/verify_repo_cleanliness.py` والتأكد من خلو المستودع وتاريخه من أي ملفات لعبة (`*.rpf`, `*.pak`, `*.wem`, `*.ytd`, إلخ) أو نصوص أصلية أو مفاتيح سرية (`.env`).
- [ ] **5. جاهزية التوثيق والترخيص:**
  - [ ] مراجعة دليل التثبيت ([docs/install-and-qa-guide.md](install-and-qa-guide.md)) وتراخيص الخطوط العربية (`SIL OFL 1.1`) وتحديث جدول التقدّم في `README.md`.

## English Summary

This guide covers Milestone 7 (`#22`, `#23`, `#24`):
- **User Install Guide (`#24`):** Step-by-step instructions for applying **GTA6AR** patches to a legally owned copy of *Grand Theft Auto VI*, including backup steps and asset-free troubleshooting.
- **QA Plan (`#22`):** Structured test scenarios across UI, subtitles, AI voice dubbing, and AI images, plus a clean bug-reporting template that references only string/batch IDs without game dumps.
- **v1.0 Release Checklist (`#23`):** Final release gate verifying coverage, minimum AI models (Gemini 3.8 Flash+, ElevenLabs v4+, OpenAI Sunburn+), automated glossary/timing checks, and zero game files or secrets via `tools/verify_repo_cleanliness.py`.
